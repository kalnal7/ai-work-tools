# PHOTOSHEET · 사진대지 만들기

사진을 넣고 설명을 적으면 A4 세로 엑셀 사진대지를 만듭니다. 사진 회전을 바로잡고 촬영일순으로 정리합니다. 외부 API 없이 내 컴퓨터에서 처리합니다.

## 설치와 실행

Windows, Python 3.10 이상이 필요합니다. 이 폴더에서 아래 세 줄을 실행하세요. 처음 패키지를 설치할 때만 인터넷이 필요합니다.

```bat
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
run.cmd
```

`run.cmd`가 화면 없이 로컬 서버를 실행합니다. 브라우저에서 `http://127.0.0.1:8501`을 여세요. 종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

## 사용 방법

1. JPG·PNG 사진을 끌어 넣습니다. 한 번에 200장, 장당 15MB 이하입니다. 여기서 1MB는 1,048,576바이트입니다. 다시 고르면 기존 선택을 바꿉니다.
2. 설명 표에서 구분(전·중·후·기타), 위치, 내용, 촬영일을 적고 순서 숫자를 바꿉니다. 같은 순서 숫자는 기존 순서를 유지합니다.
3. 왼쪽에서 2·4·6칸과 표지 정보를 정하고 미리보기를 확인한 뒤 **엑셀 사진대지 저장**을 누릅니다.

`바닥_방수전.jpg`는 위치와 내용을 자동 채웁니다. `IMG_0412.jpg` 같은 카메라 기본 이름은 빈칸으로 둡니다. 파일명·내용의 단어 끝에 전·중·후가 있으면 구분도 자동 채웁니다(방수전, 시공중, 완료후, _전, (후)). 전기·후면은 기타로 둡니다. 여러 구분이 섞이면 기타로 두며, 구분을 직접 수정할 수 있습니다. 내용을 바꾸면 구분을 다시 채웁니다. 촬영일을 편집해도 순서 숫자는 자동으로 다시 매기지 않습니다.

촬영일은 EXIF 촬영일을 우선 사용합니다. 촬영일이 없으면 브라우저가 읽은 파일 수정일로 정렬하고 **촬영일 없음**으로 표시합니다. 업로드 순서와 컴퓨터의 시간대를 기준으로 표시하는 날짜에 유의하세요.

전·중·후 묶기를 켜면 일반 배치 선택보다 우선하여 **3열 × 2줄(6칸)**로 놓습니다. 같은 위치를 전·중·후 열로 정리하기 위해서입니다. 같은 구분이 여러 장이면 다음 줄로 이어지고 없는 구분은 빈칸으로 둡니다. 위치가 없거나 기타인 사진은 묶음 뒤에 놓습니다.

사진 칸은 해당 쪽 가로 사진 비율의 중앙값과 좌우 약 4px 여백에 맞춥니다(가로 사진이 없으면 4:3 기준). 2칸은 2열×1줄, 4칸은 2열×2줄, 6칸은 3열×2줄이며 남는 공간은 쪽 아래에 둡니다. 세로 사진은 비율을 유지해 가운데 놓습니다.

## 한계

- HEIC는 다음 판에서 지원할 예정입니다. JPG나 PNG로 바꾸어 넣어 주세요.
- 사진은 긴 변 최대 1600px, JPEG 품질 85로 넣고 투명한 부분은 흰색으로 바꿉니다. 원본 EXIF는 내보내지 않습니다.
- 작은 원본은 엑셀 문서의 부가 정보 때문에 저장 크기가 늘 수 있습니다. 사진을 많이 고르면 메모리와 시간이 필요합니다.
- 설명이 길면 고정된 칸에서 일부가 보이지 않을 수 있으니 짧게 적어 주세요. 미리보기는 같은 배치와 크기를 사용하지만 글꼴·줄바꿈과 인쇄 결과는 엑셀 프로그램마다 차이가 날 수 있습니다.
- 처리 속도, 인식 정확도, 법정 서식 적합성을 보장하지 않습니다. 회사나 제출처의 양식은 별도 확인이 필요합니다.
- 한글(HWP) 양식, 회사 서식 맞춤, 사진 자동 분류, 대량 폴더 일괄 처리는 맞춤 범위입니다.
