# 가상 현장 시연

`photos/` 바로 아래 JPG 17장은 모두 AI로 만든 가상 사진입니다. 실제 공사·점검·방수 성능을 입증하는 자료가 아닙니다. 가상 현장은 상가 1층 화장실 방수 공사이며 사람 얼굴·글자·로고가 없습니다.

17장을 함께 고르면 회전 보정 5장, 촬영일 없음 1장, 구분 자동 9장으로 표시됩니다. 파일명에 단계가 없는 카메라 기본 이름 8장은 기타입니다. 내용을 전·중·후로 입력하면 구분도 자동으로 바뀝니다. 구분은 직접 수정할 수 있습니다.

사진은 EXIF 회전 정보와 촬영일을 포함합니다. 1장은 촬영일 없이 파일 수정일로 정렬됩니다. 전·중·후가 다른 사진은 독립 생성되어 같은 위치라도 세부 형상이 완전히 같지는 않습니다.

JPG만 공개 시연에 포함합니다. 생성 원본·프롬프트·제작 스크립트·검증 자료는 공개 대상이 아닙니다. 사진 생성 기능은 앱에 포함하지 않습니다.
